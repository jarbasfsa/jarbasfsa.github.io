Política de Privacidade — Nova FM Ubaíra

A Nova FM Ubaíra respeita sua privacidade e está comprometida em proteger as informações dos usuários.
Este aplicativo não coleta, armazena nem compartilha dados pessoais de forma direta.

Coleta e uso de informações

O app pode utilizar serviços de terceiros, como o Google AdMob, que podem coletar dados não identificáveis, tais como tipo de dispositivo, sistema operacional, e comportamento de uso, para exibir anúncios personalizados ou genéricos.

Mais informações sobre como o Google trata os dados podem ser encontradas aqui:
👉 https://policies.google.com/technologies/ads

Permissões

O aplicativo utiliza apenas as permissões necessárias para:

Acessar a internet e reproduzir o streaming da rádio.
